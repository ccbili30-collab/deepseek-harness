# Noven 空态设计契约

设计图：同目录 `index.html`（19 张，均以真实空态截图图生图）。

## 0. 总则

- 空态不是“零数据兜底页”，是该模块的**第一张空白表单/第一块空白画布**。
- 禁止出现：`还没有条目`、`No items yet`、`Nothing yet`、`Add <module>`、居中的空文案、只有 `Name` 表头的空表、原始 JSON、英文按钮。
- 禁止用假数据填充：不写示例世界/角色/地名/事件/关系；允许空占位符和字段名。
- 首屏直接出现可填结构；不要“点添加 → 弹窗表单 → 回来”。
- 新建卡：只有世界/角色，选中、命名、创建；创建后总览必须列出该卡全部模块。
- 概览卡显示模块名、`空白` 状态和该模块的迷你骨架；不显示 JSON，不丢模块。
- 所有菜单/浮层 portal 到 body，不能被滚动容器裁切。
- 页面内容宽度 666px；标题 32/40，页头下 1px 分隔线；正文 14–16px；字段名 12px `#8A8F94`；纸面 `#FFFFFF`；页面底 `#F4F5F4`；主色 `#34D399`。
- 表单卡：白底、1px `#ECEEEF` 边框、12px 圆角、24px 内边距；输入区为淡色下划线/淡灰输入框；字段为空时只显示字段名和占位，不显示示例值。
- 主按钮：薄荷绿底白字；次按钮：白底细边框。首表单底部右侧 `保存`，左下角 `＋ 再加一条…`。
- 保存后表单变成正式条目；`再加一条` 创建下一条空白表单。没有内容时点 `取消` 不落库。
- 空态表单直接可编辑；保存前不生成临时假条目到列表；保存后才进入正式数组。
- 字段名和输入提示二选一：输入框外已有字段名时，框内不再重复「请输入…」；行内自解释的下拉/输入不再另加一排列标题。
- 空白表单只保留一个主按钮（保存）和一个文字级次入口（再加一条）；不把解释文案、候选来源说明放到首屏。

## 1. 世界总览

- 顶部：卡名 `w`，右侧 `World` + `⋯`。
- 内容：两列模块索引，列出世界卡全部 9 个内容模块：世界档案、地图、地理、势力、种族、时间线、关系、文化、规则。
- 每卡：左上模块名，右上浅灰 `空白`；内部只放该模块的浅灰迷你骨架（头像是框、地图是网格、时间线是轴、关系是点线、规则是左栏+线）。
- 底部居中 `＋ 新建模块`。
- 点卡片进入模块；总览不显示任何 JSON 或原始数据。

## 2. 世界档案

- 顶部：`‹ w`、`世界档案`、右侧 `World · 世界档案` + `⋯`。
- 一张档案纸：左 3:4 封面占位 `封面`；右字段 `名称`、`世界类型`、`尺度`、`历法`、`一句话`。
- 下半部 `世界概述` 多行正文。
- 底部 `取消`、`保存`。
- 没有 `No items yet`，没有添加按钮；档案默认就有一张空白表单。

## 3. 地理

- 一张地理表单：左 16:9 `地貌图`；右 `名称`、`地貌`、`气候`、`主要势力`。
- 下方 `说明` 多行。
- 左下 `＋ 再加一处`，右下 `保存`。

## 4. 势力

- 一张势力表单：左 1:1 `徽记`；右 `名称`、`立场`、`实力`、`驻地`。
- 下方 `说明` 多行。
- 左下 `＋ 再加一方`，右下 `保存`。

## 5. 种族

- 一张种族表单：左 3:4 `肖像`；右 `名称`、`寿命`、`分布`。
- 下方 `特征` 多行。
- 左下 `＋ 再加一族`，右下 `保存`。

## 6. 文化

- 一张文化表单：左 16:9 `封面`；右 `名称`、`类别`、`场合`。
- 下方 `说明` 多行。
- 左下 `＋ 再加一条文化`，右下 `保存`。

## 7. 地图

- 标题 `地图`，右侧 `World · 地图`。
- 空白画布：淡灰米白底、极淡经纬/等高网格，不放假地名、假道路、假标记。
- 画布左上：`导入底图`（主）、`生成地图`（次）。
- 画布中央：虚线落点框 + 薄荷绿加号 + `放置第一个标记`。
- 画布左下：`底图`、`标记`、`范围`；右下：`－ 100% ＋ 适配`。
- 空态不出现 `No base image yet` / `pick a way to start`。

## 8. 时间线

- 标题 `时间线`，右侧 `World · 时间线`。
- 顶部左 `0 个事件`；右侧 `历法 / 跨度` + `＋ 添加事件`。
- 横轴使用当前历法；空态默认相对刻度（如前 400、前 200、0、200、400），不得硬编码公元 1000–2000。
- 轴下直接显示第一张事件表单：`时间`、`事件名称`、`关联地点`、`说明`；保存后落到轴上。
- 不出现 `Nothing yet`。

## 9. 关系（世界）

- 上部关系图：浅米白画布，中央虚线 `添加第一个关系` 节点，左右各一个淡虚线实体占位。
- 不放「图是视图…」说明；图只负责表达关系，表单负责编辑。
- 下部只有一行紧凑输入：`[选择角色 / 势力] → [关系（盟友 / 敌对…）] → [选择角色 / 势力] [保存]`。
- 不设「从 / 关系 / 到」三个外部标题，不设备注大框，不设候选来源第二行说明；候选范围写在目标下拉的占位里。

## 10. 规则

- 左侧 96px 分类栏：`全部`、`未分类`；空态不造示例分类。
- 右侧第一张规则表单：`规则名称`、`分类`、`一句话`、`规则说明`。
- 底部 `保存规则`；右上浅色 `＋ 再加一条`。
- 不再出现只有 `Name` 表头的空表。

## 11. 角色总览

- 顶部：角色名、`Character` + `⋯`。
- 必须列出全部 8 个模块：角色档案、关系、行动轨迹、多形态、语录、能力、装备、图集。
- 角色档案为横向首卡（小肖像 + 三行字段线）；其余 7 个两列网格；每卡右上 `空白`，内部是浅灰迷你骨架。
- 底部 `＋ 新建模块`。
- 不允许丢模块、不允许 JSON。

## 12. 角色档案

- 一张档案纸：左 3:4 `肖像`；右 `姓名`、`身份`、`年龄`、`阵营`、`出身`。
- 肖像下 `性格关键词` 空白 chip 输入位；右侧 `一句话`。
- 下半部 `外貌与气质`、`性格与习惯` 两段空白正文。
- 底部 `取消`、`保存`。
- 没有 `No items yet`；默认存在一张空白档案表单。

## 13. 关系（角色）

- 上部关系图：中央灰色人物剪影占位 + 角色名 + `本人`；虚线箭头指向 `添加关系` 虚线节点。
- 不放「图是视图…」说明。
- 下部只有一行紧凑输入：`[空角色测试] → [关系（师徒 / 宿敌…）] → [选择角色（本卡 / 世界）] [保存]`。
- 不设「从 / 关系 / 到」三个外部标题，不设备注大框，不设候选来源第二行说明。

## 14. 行动轨迹

- 顶部左 `个人经历`；右上 `历法 / 跨度` + `＋ 添加记录`。
- 纵向年龄轴，浅灰刻度（0 岁、10 岁、20 岁），不放假事件。
- 轴下第一张空白记录表单：`年龄`、`事件名称`、`说明`、`关联角色`、`关联关系`。
- 保存后成为轴上第一条记录；不出现 `No entries yet`。

## 15. 多形态

- 顶部引用条：`引用角色档案 · <角色名>` + `打开来源` + `（将覆写而非复制）`。
- 第一张形态表单：左 3:4 `肖像`；右 `形态名称`、`主形态` 单选、`覆写字段` 四行（`身份`、`年龄`、`阵营`、`出身`），每行右侧 `继承自角色档案`。
- 底部 `保存形态`、`取消`；下方 `＋ 再加一个形态`。
- 不出现 `Add form`。

## 16. 语录

- 一张语录表单：大引文输入区，左上引号装饰，占位 `写下一句会记住的话`。
- 下方 `场景`、`情绪`、`对象` 三个可编辑字段。
- 左下 `＋ 再加一条`，右下 `保存语录`。
- 不出现 `Name` 表头、不先点 Add。

## 17. 能力

- 一张能力表单：`能力名称`、`类型`、`一句话简介`、`效果`、`代价（可选）`、`冷却（可选）`。
- 左下 `＋ 再加一条`，右下 `保存能力`。
- 代价/冷却明确标注可选，不强制。

## 18. 装备

- 一张装备表单：左 1:1 `器物图`；右 `装备名称`、`类型`、`归属`；下方 `效果 / 说明`。
- 左下 `＋ 再加一件`，右下 `保存装备`。

## 19. 图集

- 三列等大 3:4 图片位。
- 第一格：上传卡，中央加号 + `添加图片` + `拖入图片或点击选择`。
- 第二、三格：更浅的空白图片位，只显示淡图片图标，不放假图。
- 不出现居中的空文案、巨大虚线块。

## 验收

- 逐页对照 `index.html` 截图，版式、字段、按钮层级和留白一致。
- 所有模块页首屏都有可操作结构；没有任何 `No items yet` / `Nothing yet` / 原始 JSON / 英文按钮。
- 新建世界和角色后，总览列出全部模块。
- 角色档案、世界档案都有空白表单，不是空文案。
- 关系图在图上方、关系行在下方，箭头有方向，候选来源明确。
- 所有新增/保存/再加一条动作不弹独立编辑抽屉；表单在页面内。
