# 对话内联块 · 注册计划（v3：引用与消息内组件）

## 0. 判据

机制完成不等于功能完成。`code` 与 `module` 各自需要规格、fixture、契约测试、文档条目和启动注册校验。模型可见目录必须由同一份组件定义支撑，真实模型回合和应用视觉验收单独记证据。

## 1. 词汇表

| id | 内容归属 | 尺寸 | 交互 | 状态 |
|---|---|---|---|---|
| `code` | 消息内的版本化组件 JSON（`data`） | 自然高度；媒体与图表管理内部几何 | 本地交互；选择进入真实草稿 chip | **组件实现、契约测试与隔离 Web 验收已落地，真实模型验收待做** |
| `module` | 宿主对象（`card:<cardId>/<moduleId>`） | 16:10；变体 `wide`、`square`、`tall` | 只读；地图/HTML 保留查看手势 | **十类模块与真实视觉验收已落地** |

`code` 不再引用工作区 HTML。模型只组合宿主预置组件，不写 HTML/CSS/JavaScript/SVG，不创建文件或模块。完整档案、集合、时间线、关系、地图、场景、HTML、3D 和文档仍由 `module` 覆盖，profile 与 graph 继续作为 collection 视图。

## 2. 已落地

- 核心指令：`src` 与 `data` 二选一，坏 JSON、半行、缺字段或混用仍是正文；流式末尾未封闭指令隐藏。
- 稳定身份：Turn/step 加源偏移定位块与选择组，流式追加不重建已有块。
- 引用规格：保留声明比例、来源解析和尺寸变体；数据规格使用自然高度并接收媒体解析与可选提交回调。
- Noven 组件：3 个现有能力适配（text/media/icon）与 17 个组件，覆盖布局、OC 叙事、协作、视觉和轻量数据表达。模型目录、校验 fixture 和系统提示共享组件 id。
- 选择提交：稳定块/组前缀生成引用，当前 Session 的草稿执行追加或同组单 chip 替换；codec 在发送时输出普通文字，失败沿用现有恢复语义。
- 旧文件式 `CodeBlock`、frame 来源、HTML 写文件提示与三个 HTML 图表模板已移除。
- 验证：核心 33 项、真实 Chat/Conversation 注入 14 项、Noven inline-code 7 项、既有模块 24 项通过；ui-chat 与 shell 类型检查及 shell 生产构建通过。
- 模块视觉：共享 FMG 宿主改为纵向 flex，iframe 不再退回 150px；只读注入覆盖当前 `#nv-*` 工具条。隔离验收台实际准备并保存地图，十类模块逐张截图检查，地图宿主、iframe、SVG 同高且刷新后重载成功。

## 3. 验收与剩余边界

1. **已完成**：隔离 Web 挂载覆盖全部组件的消息，真实加载 SVG 资源，检查宽窄屏、深浅色、历史重渲染和无 iframe；逐区域截图已人工核对。
2. **已完成**：同组 chip 替换、不同组追加与普通文本发送通过，工作区文件集合不变；侧车后台会话完成后再退出，未留未处理错误。
3. **已完成**：文档、档案、关系、集合、时间线、地图、自由界面、自由 3D、场景、HTML 十类 `module` 均有真实内容；地图完成构图、定稿、人文层、保存与刷新重载，最终十张居中截图及 `PAGE_ERRORS=[]` 已核对。
4. **未执行**：当前环境没有 `GMN_API_KEY` 或 `DEEPSEEK_API_KEY`，真实模型回合未运行；模型提示契约已验证所有组件 id 和示例，但这不替代真实模型验收。
5. `module` 的嵌套 iframe 焦点桥与滚轮归属仍属独立问题；普通 `code` 不使用 iframe，不需要这套桥。
6. 画布与独立预览尚未挂载同一注册表；挂载时必须复用相同组件和 props，不复制渲染分支。

## 4. 不得回退的规则

1. 只有 `code` 与 `module` 两个顶层块类型，内部组件不扩张顶层注册表。
2. 轻量内容属于消息；已有完整界面只引用，不能复制成另一套实现。
3. 模型只见组件目录，不见宿主 HTML/CSS/脚本；所有模型 JSON 先校验再渲染。
4. 选择只在用户提交时成为文字，查看和点击不同步模型状态。
5. 类型缺失或数据错误显示受控提示，不把原始 JSON 或源码倾倒给读者。
