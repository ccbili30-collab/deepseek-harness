# 工作表

多工作方的协调台账。约定：

- **开工先登记**：在「正在开工」写一行——你是谁、做什么、会动哪些文件（写到目录/文件级）。写完再动手。
- **动手先读表**：别人「在做」里占着的文件不要碰；要碰先对齐。
- **完工要销记**：删「正在开工」那行，把事项挪到对应域的表格里（状态=完成），日志补一行"做了什么、哪些文件已放开"。
- **留痕粒度**：记"文件+意图"，不抄 diff（git 里有）。
- 域内状态：想法 → 待办 → 在做 → 完成 / 搁置。每项"在做"同时只允许一个工作方。

署名约定：桌面端 = `devin-desktop`；手机端/其他方自选取名，第一次写表时顺便登记。

**迁移总纲**：界面体系迁移（工作台 → 内容树 + 画布标签页）的决策、阶段、红线、防跑偏机制见 [迁移任务书.md](迁移任务书.md)；接口与数据格式见 [契约.md](契约.md)；怎样算做完见 [验收场景.md](验收场景.md)；设计稿见 [workbench-v2/README.md](workbench-v2/README.md)。**做迁移相关的活之前先读任务书 §0。**

## 词汇

- **物件卡 / 记录卡**：默认形态 = 纯 tile + 空气铭牌（标题/meta 排在页面空气里）；白底信息带只留给信息流、档案、表单这类"记录"场景
- **sidecar / 设定助手**：常驻侧边的第二个 agent——消化模式（每轮读主对话增量整理实体）+ 讨论模式（侧聊）
- **proto-card**：实体条目 = 草稿卡，"收下"转正走 CardStore
- **推回**：侧聊结论蒸馏成一条用户消息发回主对话
- **项目 > 会话**：资产（卡/实体/工作台布局）按 workspace，上下文（卡绑定/转录）按 session
