# 《灯烬纪》宣传片制作计划（拍片蓝本 v1）

> 用途：阶段 A（在诺文里养出真实世界）与阶段 B（成片）共用的执行蓝本。
> 片长目标 2:50｜16:9｜3840×2160 母版、1920×1080 主发版｜60fps｜无人声旁白。
> 唯一母题：**点灯**。全片只有一种转场语言（光）、一种叙事动作（点亮）、一种情绪（朝圣）。

---

## 1. 一句话定义

一个人在黑暗里说了一个念头；很多轮问答之后，他说了一句话，整个世界被点亮、被郑重地一件件呈上来。

观众要带走的不是"这软件功能多"，而是三句体感：

1. **我聊的天没有一句白费。**
2. **我不会画图、不会排版，但我的东西被生成为艺术品。**
3. **这些是我的——每一笔都是我定的。**

## 2. 情绪曲线（全片为什么这样剪）

```
序章(冷/远) → 一问一答(渐密、克制、只有对话) → 抽空一拍(静)
→ 一句话 → 落盘 drop(全片能量峰) → 巡礼(缓慢、神圣、一件一件点亮)
→ 回到日常工作台(踏实、归属) → 落版(一粒灯芯)
```

全片只有**一个能量峰**（结晶落盘，00:59）。峰前全部压低，峰后不许再炸，用长时间的"慢与美"兑现峰值的承诺。宁可闷一点开场，不能把落盘拍得普通。

## 4. 分幕详案

### 序章·点灯（0:00–0:14）

- 全黑保持 3 秒不放任何东西——发布会式的耐心。第 3 秒画面几何中心出现一粒暖光（直径约 6px，色温 2700K），做 4 秒一次的极慢呼吸（亮度 0.8↔1.0）。
- 两张字卡，居中，同一版式（见 §5）。不加英文副标题、不加装饰线。
- S02 末，灯光在 0.4 秒内过曝到白（峰值不超过 92%，保留一丝暖底，避免死白），白光中浮出诺文创作页窗口。**这是全片第一次、也是唯一一次"由光生 UI"**。

### 第一幕·聊（0:14–0:46）

拍法要点：**界面干干净净，只有对话在长。** 全程不给内容树、不给任何"已生成"的东西；让观众潜意识记住"此刻什么都还没有"，为 S12 储能。

- S03：完整创作页（＋创作绿键、工作区名、居中 composer、绿幕晕染）以 92% 缩放浮在纯黑中，带 60px 柔影，镜头在 7 秒内从 100% 极缓推到 103%。用户真实打字（彩排脚本，见 §9）：
  > 「我想做一个世界：太阳熄灭了三百年。黑透的地方，人会连同别人对他的记忆一起消失。」
  回车后用产品自带的仪式转场（种子起、页散、落座）进入会话——**这个转场是产品真实动效，原样录，不另加包装**。
- S04：会话栏可见"探索模式"角标。AI 气泡：
  > 「这个念头上岸，先不定任何设定。告诉我：这里的光，对人意味着什么？」
  下方两张选项卡：「A 光是最后的秩序，人人守灯」/「B 光本身成了压迫，亮处才有资格活着」。虚拟光标移到 B，单击，B 卡以产品选中态（灰底深字）定格 0.6″。
  左下角在 00:22–00:26 淡入一行 13px 暖白小字（非产品 UI，是影片字幕）：「探索模式 · 只交流，不落笔」，4 秒后淡出。全片只解释这一次。
- S05–S08：**快剪**。每轮 = 用户半句回答（打字加速 2–3 倍速）→ AI 一个追问或一句确认 → 切。镜头固定，切点压在对话气泡入场动效的中段，越剪越快（单轮时长 5″→4″→4″→内容三连 5″）。出现的内容严格按世界设定：
  - S05 规则：「被光照见的，才存在过」→ AI 追问"那灯油归谁管"；
  - S06 燃术与代价：以记忆为燃料、半蚀者；
  - S07 灯史：提灯记录的人，写下就能多存在一阵；
  - S08 三连快切：长明灯庭/拾烬者/慕暗者三个名字逐行打出 + 阿檐、沉七、谢拾遗三个名字，最后一个名字落定瞬间，**音乐滤波抽空**，环境声全灭。

### 第二幕·一句话·结晶（0:46–1:08）

- S09 七秒长镜头，不切。AI 最后一轮回答静静停在屏幕上，光标在空输入框匀速闪 2 次（约 2 秒，让观众替他着急/期待），然后逐字打出那句话，打完停 0.8″，回车。
- S10 切一个近景：composer 预设菜单，「探索模式」→「标准模式」。只给控件、光标、选中态 4 秒，配灯芯轻"噗"。不给解释字幕——动作本身人人懂。
- S11 两秒：画面不动，四边暖光像黎明一样压进来（vignette 反用：从黑到 8% 暖光），riser 起来。
- S12 **九秒结晶蒙太奇，全片命门，单独精修**。全部真实界面、真实落盘，录屏后做 1.5–3 倍的变速与 7 个切点：

  | 子拍 | 时间 | 画面（真实发生） |
  |---|---|---|
  | a | 00:59.0–60.5 | 内容树空白处，「灯烬纪」世界卡生长出来 |
  | b | 60.5–62.0 | 模块逐个挂上：世界档案·规则·地理·时间线·势力·族群·文化·关系（树行真实插入动画） |
  | c | 62.0–63.5 | 提案条出现 → 光标「全部接受」→ 提案逐条变实 |
  | d | 63.5–65.5 | 切地图模块：白膜地形已在 →「生成人文层」→ 国界、城市点真实落上地图 |
  | e | 65.5–67.0 | 时间线五纪节点自左向右点亮 |
  | f | 67.0–68.0 | 三张角色卡依次出现，画像淡入 |
  | g | 68.0–68.0→01:08 | 所有光向画面中心收束 0.5″ 再"呼"地散开——落定在世界总览页，进入巡礼 |

  音乐 drop 点压在子拍 a 世界卡名字出现的那一帧（00:59.5），钟声/钵声压在子拍 c「全部接受」。合成时叠极轻的星火粒子（见 §5），但**不许加任何假 UI**——每一帧产品画面都必须是真的。

### 第三幕·巡礼（1:08–2:18，70 秒）

统一仪式，12 件"圣物"一件一件揭：

1. 每件先用 0.8″：黑底上一条 1px 暖金光痕从左划到右（60px/s），光痕停住后浮出模块名（14px，暖白，字重 300，字距 0.08em）。
2. 随后该模块的真实页面从纯黑里被"点亮"：一层暖光径向渐变从模块中心展开（600ms，ease-out），页面浮现并开始极缓推近（5–7 秒内 100%→104%）。
3. 每件只打名字，不配解说，不做标注。音乐是同一片 pad，镜头语言只有"点亮→缓推→暗下→下一件"。
4. 角色三件用同一机位、同一构图、同一时长节奏（5–6″），让三张卡像三联祭坛画。
5. S24 自由 HTML 是巡礼的小高潮：放 7 秒，虚拟光标沿「长明京 → 千灯驿道 → 沉名故城」自动行走，光到之处黑暗褪去、城市与驿道亮起，离开后缓慢回暗（具体做法 §7）。

镜头内必须出现的真实内容要点（阶段 A 照此养资产）：

- **S13 世界总览**：世界封面图（阿檐提灯远眺层叠灯城的概念图）＋金句「被光照见的，才存在过」＋规则/五纪/势力数的概览块。
- **S14 大陆地图**：FMG 真图，暗化处理在产品地图主题内完成（无主地深色、灯油泽州暖色、沉名故城区域半暗），六块地理与关键城市名中文可读。
- **S15 3D**：见 §7 建模方案。
- **S16 时间线**：五纪从左到右视觉亮度递减，"灯烬纪"节点是唯一的绿色（活物）。
- **S17/S18**：势力四卡（灯庭/拾烬者/慕暗者/铸灯行会）、族群三类（常人/半蚀者/燃灵），每卡一句话信条。
- **S19–S21 角色**：画像（统一胸像、单侧灯火、深底）＋姓名＋身份＋一句金句，卡内其他模块淡在背景。金句备选：
  - 阿檐：「我写下的，就会有人记得。」
  - 沉七：「我已经丢了半个名字，剩下半个，得省着用。」
  - 谢拾遗：「灯若不许灭，人就只配被照管。」
- **S22 燃术规则**：富文本长卷，含"代价表"（燃用一段记忆→身体透明度），排版精良。
- **S23 残日灯**：物品卡 + 画廊（残日灯概念图、灯芯碎片特写）。

### 第四幕·它是你的（2:18–2:40）

- S25 从巡礼的"陈列"回到工作台全景：左侧卡页渲染仍开着，右侧对话活着。输入「再给阿檐补一段她在沉名故城的童年。」AI 回复并出现提案条——证明巡礼不是一锤子买卖，**世界可以继续长**。
- S26 内容树批量管理：多选几张卡、批量隐藏/移动、模块拖拽排序；一个画面里同时看见"好看的渲染"和"像文件一样可靠的管理"。配小字字幕：「好看，和井井有条，是同一个地方。」
- S27 镜头缓拉，左渲染+中树+右对话三列同框，树里世界/地图/时间线/角色/文稿全部在列。小字浮現：「你聊过的每一句，都没有白聊。」停留 3 秒后随黑场淡出。

### 落版（2:40–2:50）

- S28 黑场，前面积累的余烬粒子从四面缓缓向心收拢，5 秒收成开头那粒灯芯光——首尾闭环。
- S29 灯芯下方浮出 slogan：**「聊出你的世界。」**（字重 300，暖白），其下 12px「诺文 Noven」。若产品字标/羽毛标有正式版，用光描出轮廓（stroke-dashoffset 动画，3 秒）；没有正式动效版就只打字标，不硬造。末尾灯芯一声轻噼，全黑。

## 5. 视觉系统（包装层规范）

### 色板

| 用途 | 值 |
|---|---|
| 背景 | `#000000`，字卡底可用 `#0A0908` 做不到 1% 的暖差 |
| 灯芯暖白 | `#F5E6C8` |
| 灯火金（光痕/光晕） | `#E8B15C`，透明度按场景 4–35% |
| 正文/字卡字 | `#F2EDE3` |
| 次要说明文字 | `#8A8378` |
| 产品绿（**只允许出现在真实 UI 里**：创作键/接受键/活物点） | `#34D399` |

包装字幕一律不用绿——绿色只属于产品，观众要在潜意识里把"绿=可以行动的活东西"和产品绑定。

### 字体与排版

- 中文：思源黑体（Source Han Sans）ExtraLight/Light 为字卡与字幕主字体；金句、模块名可用思源宋体（Source Han Serif）Light 增加"典籍感"，但**仅出现在产品渲染内容内**，包装字卡保持无衬线，避免古风。
- 字卡：居中，字重 200–300，字号约 56–64px（4K 母版 112–128px），字距 0.02em，行距 1.8；单行成卡，绝不两行。
- 字卡动效：淡入 600ms `cubic-bezier(.22,1,.36,1)` → 停留 → 淡出 400ms；不加位移、不加发光（或 ≤3% 的 outer glow）。
- 模块名字幕：14–16px（4K 28–32px），字距 0.08em，暖白 85%，右下角或光痕下方固定基线。

### UI 悬浮与运镜

- 录屏窗口悬浮于黑舞台：窗口外扩 80–120px 黑边，阴影 `0 40px 120px rgba(0,0,0,.9)` + 一圈极弱暖光环境遮挡 `radial-gradient(rgba(232,177,92,.06), transparent 60%)`。
- 全片运镜只有两种：**极缓推**（5–7″ 内 scale 100→104%，曲线线性偏 ease-out）与**静**。不摇、不甩、不环绕 UI（环绕只给 3D 内容本身）。
- 标注：全片最多两处（探索模式角标说明、S26 管理字幕），用 13–14px 暖白纯文字，不用箭头、不用红框。

### 光效与粒子

- 唯一转场 motif：灯光过曝（300–500ms，暖白 92% 峰值），全片只准用 3 次：S02→S03、S12 收尾、S24→S25。
- 余烬粒子：仅序章、S12、落版出现；单画面 ≤30 粒，0.8–2px，上飘速度 4–10px/s，寿命 6–10s，景深虚化 30%，暖金 20–45% 透明。巡礼中**禁用**——让产品画面自己发光。
- 严禁：金边、纸纹、卷轴花边、哥特字、镜头光晕套素材（lens flare 贴图）、快闪转场、弹簧动效进入包装层。

## 6. 音乐与声音设计（时间轴）

- 0:00–0:14 低频 drone（≈55Hz）+ 两音钢琴（大五度，留白长尾）。
- 0:14–0:46 钢琴脉冲 8 拍渐密（对应问答加速）；0:44–0:46 低通滤波抽空，剩一颗心跳低频（~60bpm）。
- 0:46–0:59 近静默：心跳 4 下 + 0:57 起 2 秒 riser。
- 0:59.5 **drop**：低音进入 + 弦乐 swell + 一记颂钵/钟声（长延音 8 秒），S12 子拍配星火颗粒音。
- 1:08–2:18 巡礼：氛围 pad + 远钟两次（1:16、1:29）+ 大提琴长音（1:14 进）+ 无词人声 pad 可选（1:45 角色段进，2:08 退出）；整体保持"教堂空间感"混响（tail 3–4s），但不使用任何宗教旋律或现成圣歌。
- 2:18–2:40 逐层撤乐，2:33 只剩钢琴头两个动机音的回响（首尾呼应）。

## 7. 3D 与自由 HTML 模块（产品内真实资产）

> 原则：这两个镜头展示的是**诺文产品模块里实时跑的内容**，不是后期插片。以下方案用 three.js/前端技术在模块内实现；Blender 只用于包装层（序章灯芯、落版光描字标，如需）。

### 3D 模块 A：长明京圣城（主 3D 镜头，7″）

- 场景：同心圆环台地 5 层（对应种姓/亮度层级），中心圣火塔。
- 技术：three.js + InstancedMesh（约 2000–4000 个"屋舍"方块），自定义 shader：窗光亮度按到中心距离与每实例随机种子衰减；外环约 15% 实例用 noise 做"被黑暗吞蚀"（顶点微消融 + 透明），直观演出"边缘在消失"。
- 圣火塔：锥体塔身 + 顶部光柱（圆柱 additive shader，fresnel 边缘亮）+ UnrealBloomPass（strength 0.6–0.9，threshold 0.8，克制不糊）。
- 相机：35mm 等效，轨道半径缓推 + 30°/7″ 慢转，从外环暗区向中心圣火运动，结束在圣火仰角。
- 大气：暖色指数雾 `#1A120A`，余烬粒子 60 粒（此处是场景内真实粒子，不算包装层）。

### 3D 模块 B：灯烬世界数据球（与 S14 地图联动，可作 S15 前 2″）

- 暗色球面上，从 FMG 地图导出的六块地理与城市真实坐标采样为发光点：城市=小灯（大小按城市层级），驿道=灯之间的弧线（quadraticBezier + 流动虚线纹理），暗区无灯。
- 数据必须来自该世界卡地图模块的真实导出（城市/区域 JSON），实现"3D 读同一份地图数据"，镜头里可给一个数据绑定的细节：地图模块新增一座城，3D 球上对应位置亮起一颗新灯（若改造成本高，降级为静态读取，但数据同源不许手填假点）。

### 3D 模块 C（可选）：残日灯可转圣物

- LatheGeometry 灯体（古铜材质，金属度 0.9 粗糙度 0.35）+ 内部不规则碎片（emissive 暖白 + bloom）+ 玻璃灯罩（transmission 0.92）。慢自转 360°/12″。若工期紧，此镜头用 S23 物品卡概念图替代，3D 只保 A+B。

### 自由 HTML 模块：光蚀地图（S24，7″）

- 双层 SVG：底层=亮色详圖（六块地理、城市、千灯驿道、地名）；上层=暗色"未被照见"图层（`#0B0A08`）。
- 一盏 CSS/Canvas 灯（radial-gradient 蒙版，半径随"灯油"余量缓慢缩小）跟随虚拟光标移动，蒙版处揭示底层；光标离开 1.2 秒后以 0.6s 缓动回暗。
- 右下角「灯油」细条，每照亮一城消耗一丝——把世界规则做成可交互的一眼体验。
- 自动演示：程序驱动虚拟光标沿脚本路径走 长明京→千灯驿道→泽州灯油田→沉名故城（到沉名时灯油将尽、光圈缩小、画面最暗），录屏无需人手，路径可逐帧调。
- 视觉：暗色玻璃拟态面板、1px 暖描边、思源宋体地名；禁止纸纹。
- 备选 HTML 模块（若光蚀地图受模块能力限制）：灯史时间卷轴（深色竖时间轴自动滚动，事件卡随灯亮起）。

### 图片资产生成规范（用产品内置图片能力）

- 统一风格词：concept art, digital oil painting, chiaroscuro lighting, single warm lantern light source, deep shadow, amber and charcoal palette, restrained, no gold filigree, no ornamental border。
- 清单：世界封面×1、阿檐/沉七/谢拾遗肖像×3（统一胸像构图、右侧 45° 主光）、残日灯×2（灯体/碎片特写）、长明京全景×1（可与 S13 封面合并）、沉名故城氛围×1。共 8–9 张，方图/竖图按模块比例生成。
- 所有图在产品画廊/卡面内真实使用；生成失败或不美的重roll到过关，不用次货。

## 8. 录制与合成管线（agent 可独立完成）

### 录制

- 浏览器：真 Chromium + Playwright（View Transition 在内嵌浏览器会被 skip，禁用）。窗口逻辑分辨率 1680×945、`deviceScaleFactor=2` 录制（3360×1890 源素材，清晰余量），最终嵌进 3840×2160 舞台。
- 光标：隐藏系统光标，注入统一虚拟光标（暖白 12px 圆点 + 点击时 300ms 涟漪环），由 Playwright 脚本驱动，点击时刻与彩排脚本逐帧对齐。
- 每条素材录 3 条纯净版（无任何标注/字幕，标注全部后期加），录前固定：字体渲染、暗色模式、关闭无关通知与扩展、系统勿扰。
- **模型输出不可控的应对**：问答镜头在养出的"理想已成会话"中拍摄——滚动回看 + 用户输入句逐句补拍（输入框打字真实进行，历史回答滚动展示真实记录），不要求现场一次性跑完美；S10 切换与 S12 落盘在专用工作区现场真实执行，可重置重彩排 N 次取最佳条；提案"全部接受"必须真实点击、真实生效。
- 60fps 恒定；地图生成等长等待用固定速度倍率压缩，不用跳切造假。

### 合成（推荐 Web 合成管线，可像素级反复精修）

1. 建一个 3840×2160 的 HTML「时间轴舞台」工程（纳入仓库版本管理，建议 `local/design/dengjinji-film/`）：每个镜头一个 scene 节点，录屏片段以 `<video>` 内嵌，用 GSAP 或自写时间轴驱动：黑场字卡、窗口悬浮/柔影、缓推 scale、过曝转场、余烬 canvas、字幕、虚拟光标。
2. 音乐与音效在同一时间轴用 Web Audio 编排预览；最终用 Playwright 以固定虚拟时钟逐帧截获（或 MediaRecorder 录 canvas 舞台）导出无损画面序列。
3. ffmpeg 合轨、封装、输出：
   - 母版 ProRes 422 HQ 或 H.265 高码率；
   - 主发版 H.264 1080p、20–28 Mbps、+ 4K 版；
   - 静音备份版（便于二配）与封面帧 PNG（候选：阿檐肖像 / 残日灯 / 世界总览）。
4. 工程源文件（HTML、three.js、字体许可、音乐授权、原始录屏）全部留在工程目录，保证可二次精修。
5. 备选：若 Web 合成在 bloom/调色上达不到预期，黑场字卡与粒子仍用 Web，产品镜头校色调色与最终封装走 DaVinci（EDL/XML 由时间轴导出台账人工对接）。
