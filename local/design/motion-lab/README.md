# 墨宇宙 · 交互样片 01

一套关于诺文「卡、模块、数据视图」的交互样片，用来试手感，不是产品代码。单页、无外链、无第三方依赖；3D 用 CSS perspective，粒子与地图用 Canvas 2D，音效用 WebAudio 现场合成。

视觉完全按诺文现有 token：`#F4F5F4` 画布、`#FFFFFF` 卡面、`#ECEEEF` 分割线、`#34D399` / `#0E9F6E` 薄荷绿、`#16181A` 深墨正文。界面字体走系统无衬线，衬线只留给引文和正文段落。

## 打开

```sh
cd local/design/motion-lab
python3 -m http.server 8099
```

然后打开 <http://127.0.0.1:8099/>。也可以直接双击 `index.html`（音效与全屏体验以本地服务为准）。

## 操作

- 顶栏 01–07 切幕；`←` / `→` 或数字键 `1–7` 直达。
- `M` 静音/开声；`S` 慢放 3.5 倍（看曲线和错峰用）。
- 开场可选「带声音进入」或「静音进入」。
- 触屏：拖拽、点按都按同一套 pointer 事件工作；自定义光标只在精确指针设备显示。

## 七幕

1. **冷启动**：粒子聚成卡墙；悬停浮起/倾斜，点一次选中，再点展开。
2. **卡内空间**：模块沿景深排成抽屉；左侧切换，前层推进，后层退后。
3. **合集**：画廊 / 列表 / 语录墙 / 技能表 / 多形态五种形态；FLIP 形变，条目可拖拽重排，点条目开详情。
4. **关系**：力导向关系图；拖节点、邻居高亮、边上的粒子流动、滚轮缩放；点空白处清空选择。
5. **时间线**：拖拽/滚轮滑动，松手有惯性；点事件居中并展开注脚；三段纪元与流动粒子。
6. **地图**：程序生成的等高线地形；拖拽平移、滚轮缩放、点空地落标记；标记有脉冲与地名。
7. **协作**：AI 流式写出提案，接受后提案卡飞进左侧卡内落位；可撤销、可拒绝重来。

## 技术边界

- 所有动效都是真实状态变化的结果（悬停、选中、展开、切换、拖拽、接受），没有纯装饰的常驻飘浮层。
- `prefers-reduced-motion: reduce` 会关闭环境循环动画并缩短大部分过渡；粒子爆发也会减量。
- 单页、三个本地文件、无网络请求；声音全部由振荡器与噪声合成，不加载音频资源。
- 页面暴露 `window.__NOVEN__`（`go` / `start` / `hooks`）只用于本地探针与调试。
