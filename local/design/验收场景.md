# 验收场景

> 「做完」的唯一定义。每个场景对应设计稿（[workbench-v2](workbench-v2/README.md) 里的编号）和 [迁移任务书](迁移任务书.md) 的阶段。
> 没有通过对应场景，阶段就不算完成。场景里写的是**用户能看到、能点到、真的有效**的行为，而不是代码结构。

## 怎么验

- **自动化**：能写成脚本的写成脚本（`noven-cards/tests/round-trip.mjs`、`noven-docs/tests/docs-check.mjs`，新增的测试放在同一目录）。
- **界面场景**：启动 `pnpm run dev:web`，用浏览器（本机有可用的 Chrome 远程调试端口 9222 流程，见任务书 §10）逐步操作，**截图 + 读 DOM** 作为证据。每个界面场景要同时验：**刷新页面后状态仍在**、**Finder 里的目录和文件符合预期**、**Cmd+Z 能撤销**。
- **诚实界面**：每个场景都要附带「本屏每个按钮和入口」的清单，标注：真 / 隐藏 / 置灰（写明原因）。**不允许出现点了没反应的按钮。**
- 每个阶段收工时，把结果写进 `工作表.md` 的工作日志，格式见文末。

状态图例：✅ 已通过　⬜ 待做　🔶 部分

## P0 底层

### S14 抽屉并发（无图）　状态：✅ 自动化通过

- **前置**：一张有 ≥2 个文字模块的卡。
- **操作**：同时发起三路写入：人改模块 A 的文字、AI 改模块 B 的文字、AI 新增一个模块。
- **期望**：三路全部提交，没有任何一路被拒；A、B 的新文字和新增的模块都在，没有互相覆盖。
- **同一文字块**：带过期的 `expectedContent` 写同一个块 → 只拒这一块（409 `scope:'block'`，带模块/块编号），被拒的内容没有落盘；带正确期望的写入通过。
- **显式确认某一版**（导入确认）：传过期版本的 `commit` 仍被拒。
- **验证**：`round-trip.mjs` 中「三路并发写」「同一文字块读后被改」「显式传入过期版本的 commit」等断言。

### S15 手机端兼容（无图）　状态：⏸ 延后（D8：桌面端全部做完再兼容；本节是将来适配阶段的验收，现在不做）

- 桌面端写出的 v2 时间线/集合载荷，经「模拟 Android 编辑」夹具（重新编码 `nodes`/`items`，丢掉条目内部额外字段，保留顶层未知键）后，桌面端读回：事件和条目不丢，按契约 C3 的对账规则得到合理结果。
- 手机端导出的 v1 交换包导入桌面端：旧载荷原样可读，时间线事件显示为「未放置」（**这条不延后**：桌面端读旧版本是现在的硬要求）。
- 桌面端导出 → 导入 → 再导出：`extensions`（含布局载荷）和新字段逐项一致（编号除外）。

### S16 旧数据兼容（无图）　状态：⬜（P0.4 起每阶段都要复验）

- 用一份**旧的真实卡目录**（`card.json` + `revisions/` + `contents/`）作为夹具：能打开、能编辑、能导出，手机端可读的部分一字不差。
- `卡/<卡名>/` 目录布局没变；Finder 里改目录名后，扫描接管卡名，卡的编号不变。

## P1 外壳

### S1 空项目起点页（图 `01`）　状态：⬜

- **前置**：新建一个空项目并打开。
- **期望**：画布是起点页，四个入口「建一个世界 / 建一个角色 / 写点什么 / 导入已有文件」；左列没有任何分组标签，只有一行「还没有内容」，下面是「＋ 新建」和折叠的「素材与文件」；右栏 AI 有开场白。
- **诚实**：四个入口都必须真的能走完（导入 = 选文件并真的导入；写点什么 = 真的建出 `文稿/*.md` 并打开）。

### S2 建一个世界（图 `J01` → `J02`）　状态：⬜

- **操作**：点「建一个世界」→ 小面板填名字、选起手方式（空白 / 让 AI 问我几个问题 / 选模板）→ 创建。
- **期望**：
  - 左列出现「卡」分组，里面只有新世界，展开后**只有「设定总览」**；
  - 画布打开这张卡的首页：「设定总览」可直接输入，下方是「添加模块」；
  - 选了「让 AI 问我几个问题」：对话里出现一条**用户消息**（预设的采访请求）并得到 AI 的提问；
  - 磁盘上 `卡/<名字>/card.json` 存在；刷新页面后标签页和选中状态恢复；`Cmd+Z` 能撤销创建（卡进入软删除，可读回）。
- 「选模板」没有可用模板时：该选项**置灰并写明「暂无模板」**，不要放一个空壳。

### S3 添加第一个模块（图 `J03` → `J04`）　状态：⬜

- **操作**：点「添加模块」→ 模块库 → 选「时间线」。
- **期望**：左列该世界下长出一行并进入就地改名；画布新开「时间线」标签页，显示空态（「还没有事件」+「添加事件」「贴入文字」）；`Cmd+Z` 撤销后模块消失。
- **诚实**：模块库里**只列真能建、真有编辑器的类型**（P1 阶段 = 文档；P2 起 + 时间线 + 集合）。地图、关系图、图集这类还没有的，**不出现**。

### S4 建一个角色（图 `J06` → `J07`）　状态：⬜

- **期望**：选中某世界时默认「放进世界」，创建后在该世界的「角色 N」里出现；选「独立角色」则出现在「卡」分组顶层；画布打开角色卡，起手模块按 Q4 的结论。

### S5 入口（图 `J05`）　状态：⬜

- 悬停世界行出现「… +」，`+` 的提示是「添加模块」；点底部「＋ 新建」弹出菜单：世界卡 / 角色卡 / 文稿 / 模块… / Studio 页面，**每一项都真的能创建**；暂不支持的（若有）置灰并写明原因。

### S6 世界总览，自动布局（图 `02`）　状态：⬜

- **期望**：世界卡首页由模块类型决定的小块拼成（地图缩略图 / 时间线条带 / 集合卡片墙 / 最近改动），没有任何硬编码的示例数据。
- **刷新**：AI 在后台新增一个模块，总览在 **2 秒内**出现对应小块（轮询，C8）。
- **空**：没有对应编辑器的模块类型，小块显示类型名和「暂时只能在素材里查看」，**不白屏**。

### S18 错误与空态　状态：⬜

- 模块类型未登记 → 画布显示友好提示，不白屏、不抛错。
- 卡目录在 Finder 里被删除或改名 → 内容树刷新，当前标签页给出可理解的状态（含「重新定位」入口的占位须是真的，否则不出现）。
- 路由失败 → 设计的错误页（`probeFrame` 兜底已有），不出现裸「not found」。

## P2 编辑器

### S7 文档编辑（图 `03`）　状态：⬜

- 选中一句话 → 浮出工具条（加粗 / 斜体 / 链接 / 问 AI）；点「问 AI」→ 输入框上方出现「已选中」标签，发出的消息正文以 C4 的标签开头；
- 编辑保存无感（自动保存，状态行显示「已保存」）；
- AI 同时改**同一个文字块** → 只提示这一块冲突并保留你的草稿（沿用 `DocStage` 的乐观锁保存事务），其他块不受影响。

### S8 时间线：加事件（图 `J11`）　状态：⬜

- 点「＋ 事件」→ 轴上出现新事件，标题输入框已聚焦；日期默认取当前视图中点；时代按位置自动归属；回车写入（一条 `timeline_add_event`），Esc 取消且**不写入任何东西**。

### S9 时间线：拖动事件（图 `J12`）　状态：⬜

- 拖动时显示日期气泡；靠近刻度时吸附（按住 Shift 取消吸附）；松手只产生**一条**命令；一次 `Cmd+Z` 回到原位。

### S10 时间线：拖时代边缘（图 `J13`）　状态：⬜

- 拖两个时代之间的边界：整条时间线出现贯穿的虚线，气泡显示「时代名 起 – 止」；落在新范围内的事件着该时代的色；松手一条命令；一次撤销还原。

### S11 AI 批量提议（图 `J14`）　状态：⬜

- 用户贴一段编年史文字 → AI 通过 `timeline_*` 工具产出事件和时代 → 画布以**幽灵态**显示；顶栏「AI 整理出 N 个事件 · M 个时代」；
- 逐条「接受 / 拒绝」、「全部接受」、「拒绝」都真的有效；接受后变实线并写入正式版，拒绝后消失；
- 提案期间用户仍可编辑别的东西，**不会因此连带接受提案**（C5 的陷阱）；
- AI 的回执写「已作为提案放在画布上」，**不宣称已完成**。

### S12 集合（图 `06`、`J16`）　状态：⬜

- 新建合集 → 加字段（选类型）→ 加条目 → 切到卡片视图 → 点开条目页 → 给条目加封面图（走卡的资源）。
- 手机兼容（延后，D8）：导出 → 经「Android 编辑夹具」→ 导入回桌面，自定义字段值和图片引用仍在（`values` 以条目编号为键，C3）。
- 视图切换里**只放已实现的**（列表、卡片）；时间轴、地图视图不出现。

## P3 总览布局

### S13 总览布局编辑（图 `J08`、`J09`、`J10`）　状态：⬜

- 进入编辑态：每个小块有拖动把手、隐藏、缩放角；末尾「添加小块」，可选清单里只有真有的小块；
- 拖动时小块抬起、落点是虚线、其他小块让位、气泡提示；松手一条 `set_layout`；`Cmd+Z` 还原；
- 对 AI 说「把大陆图放大，放到左边」→ AI 通过布局工具改，**作为提案**叠在画布上，可接受 / 拒绝；
- 布局存卡的 `extensions['noven.layout.overview']`；导出包带着它；手机端行为不在本轮验收范围（D8）。
