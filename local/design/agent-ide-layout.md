# Agent / 手作固定镜像布局

> 2026-10-27 与用户逐轮确认。本文是当前外层布局的设计锚点；旧的自由换位、`agent` 停靠画布与 `ide` 抬起画布不再作为 Noven 产品路径的目标行为。2026-10-28 起的逐条原型反馈与修正见 [三视图原型校准记录](原型校准记录.md)，正式实现必须一并遵守。

## 1. 空间规则

整个应用只有三种区域语义：

- **左侧导航栏**：组织当前工作。Agent 显示工作区与会话列表；手作显示内容树。
- **中间主工作区**：当前模式的主角。Agent 是当前对话；手作是画布。
- **右侧辅助区**：可以展开或折叠的另一工作面。Agent 是画布；手作是当前对话。右侧内容树只在 Agent 呈现，IDE 不再复制第二棵树。

两种模式的固定顺序为：

```text
Agent
[导航栏 + 会话列表] [当前对话：主工作区] [可折叠画布]

手作 IDE
[导航栏 + 内容树]   [画布：主工作区]     [可折叠当前对话]
```

中间永远是主工作区，右侧永远是辅助区。不得通过拖放改变外层区域的职责或顺序。

### 唯一控制权

Noven 产品外壳统一持有唯一的 `mode: 'agent' | 'ide'`，只有 Agent／手作按钮能改变它。模式不是 Session 几何、画布停靠状态或导航历史的派生结果。

- 对话模块只显示对话，不决定自己是否为主区。
- 画布模块只显示画布，不决定自己停靠在哪。
- 导航模块只显示当前模式要求的列表，不因切换会话而重排页面。
- 布局组件只负责宽度、折叠、顺序和渲染，不另存一套产品模式。
- 切换会话、打开文件、进入历史记录不得改变 `mode` 或重新排列主布局。

代码可以继续分模块，但页面控制权不得分散。树按当前会话读写项目数据只是数据访问细节，不代表树或页面模式归 Session 所有。

## 2. 初始界面与进入路径

初始创作页保持现有视觉与交互：左侧为导航栏和会话列表，中间为创作首页，工作区左抽屉默认隐藏。

- **直接对话**：进入 Agent。整体布局不变，右侧出现折叠画布入口。用户展开后直接使用画布；Agent 中画布的树可以独立打开或隐藏，不替换左侧会话列表。
- **点击手作**：进入手作 IDE。左侧会话列表换成内容树，画布成为中间主工作区，当前对话位于右侧并可折叠。

已确认的创作首页不是一次性欢迎页，而是 Agent 新会话状态。已有会话在同一主区域显示对话、执行状态、提案与结果。

## 3. 切换按钮

提供位置固定的 **Agent／手作** 切换按钮。初始页的大“手作”入口保留，和固定按钮调用同一动作。

一次切换同时提交三项状态：

| 区域 | Agent | 手作 IDE |
|---|---|---|
| 导航栏 | 会话列表 | 内容树 |
| 中间主区 | 当前对话 | 画布 |
| 右侧辅助区 | 可折叠画布 | 可折叠当前对话 |

切换不得新建会话、重建画布、清空页签或草稿，也不得暗中更换项目。固定按钮只写 `mode` 并返回 Conversation；初始页若尚无宿主，仍先执行原有的宿主准备，完成后调用同一个 `changeMode`，不为模式切换新建项目或另起业务现场。

## 4. 折叠与会话历史

“会话列表”和“当前对话”是两种不同状态，不得混用折叠逻辑：

- 会话列表是会话导航。手作中不占左侧栏，通过小时钟临时打开；选择后仍回到内容树。
- 当前对话是协作面板。Agent 中占据中间主区；手作中位于右侧，可像 VS Code 侧栏一样折叠。
- Agent 中左侧仍为会话列表；手作中左侧为内容树。另一套导航保留在固定的折叠入口中。

## 5. 拖动与状态保留

取消的是**外层三区域的自由拖动换位与任意排布**，不是全部拖动：

- 保留正常的区域宽度调整。
- 保留画布内部页签、分屏与对象拖放。
- 保留各区域自己的展开、折叠状态。

模式切换只改变呈现状态。当前会话、画布页签、编辑器内容、终端和输入草稿必须连续；从手作返回 Agent 时恢复同一对话，从 Agent 返回手作时恢复同一画布现场。

## 6. 范围

全局设置不进入画布。本设计只改共享客户端的外层布局与 Noven 产品编排，不改 Session 数据格式、卡存储、项目目录或三条合并线的功能实现。

## 7. macOS 验收约束

macOS 收起左侧栏时整栏隐藏，不保留 Web 的窄轨。Agent／手作按钮必须同时在 `shell.leading.action` 的顶部恢复区提供，保证侧栏隐藏后仍可切换；其他平台继续使用侧栏底部按钮。Noven 存在第三个顶部控件时，普通窗口的 leading clearance 为 196px，全屏窗口为 120px；默认 DSH 保持 160px/84px。

侧栏透明度、颜色、标题栏安全区、折叠后的可见性和恢复入口以真实 macOS 为准。Web 只用于验证模式状态、内容导航、保活和交互，不能作为视觉验收依据。桌面视觉验收使用反色图标的 Noven Test 候选包与隔离数据目录，不替换正式应用。

## 8. 对象顶栏、命名与动效

Agent／手作只换区域，不删对象能力。对话和画布各自保留顶栏：标题、导航与操作按对象归属，不能因空白 Session、自绘 `selfChrome` 或模式切换而失去入口。

- 以往对话统一叫“会话列表”，小时钟复用完整 Session 浏览器；手作临时展开后，选择会话或显式返回都恢复内容树，不改变 `mode`。Create、空白会话、内容树和 macOS 恢复区共享同一入口。
- 当前 Agent 执行过程叫“执行记录”，文稿／卡／文件的历史叫“版本”。画布页签条负责打开对象，对象工具栏负责当前对象的视图、设备与版本，不再统称“切换菜单”。
- 对话视图切换与画布功能导航不得被 Noven CSS 一刀切隐藏。自绘画布提供可见的页签切换与工具菜单，所有功能入口共用 Session 明确的路由，不能重入或落入另一 Session。
- 显式模式切换由唯一事务协调：稳定区域使用可中断的 FLIP 换位，复合场景退化为轻量过渡；首帧、Session 恢复、窄屏、全屏、创建场景和 reduced-motion 不叠加另一套动画。折叠开始即禁止交互，退出画面随轨道淡出，不重建 Conversation、编辑器或终端。

## 9. Web 的 macOS 镜像

默认 Noven Web 使用独立的 `data-chrome-platform="darwin"` 呈现标记反向镜像打包 macOS 的普通窗口，不改变真实 `data-platform`、Web 快捷键或原生能力。共享整栏隐藏、恢复入口、标题栏几何、材质和动效；原生全屏、真实 vibrancy、窗口生命周期、Dock／托盘、协议与签名仍分别验收。完整对照和启动隔离见 [web-pc-mirror.zh.md](web-pc-mirror.zh.md)。
