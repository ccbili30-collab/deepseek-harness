# 内联块

[English](inline-blocks.md) | 中文

内联块是 assistant 正文里的一个封闭单元。它要么引用已有对象，要么携带属于当前消息的组件数据。封闭顺序、明确的内容归属、焦点激活和与内容匹配的尺寸规则，共同约束流式输出、身份、键盘和布局。

## 指令

只有一整行是完整的 `::view{...}` JSON 对象，带非空 `block`，且恰好有一个内容字段时，块才存在。`src` 指向已有对象；`data` 是属于消息的 JSON 对象。半行、坏 JSON、缺少或混用内容字段、指令前后还有别的文字，都仍是普通正文。消息流式输出时，末尾尚未闭合的指令会隐藏，不先把源码画成正文。

```text
::view{"block":"code","data":{"version":1,"component":"text","text":"阿七第一次出场。"}}
::view{"block":"module","src":"card:card-1/module-1","size":"wide"}
```

第一个例子直接显示宿主预置的文字组件，不创建文件或卡片。第二个显示已有卡片模块。引用类型可以声明命名的 `size` 变体；未知变体退回类型默认值。

## 分段与身份

`splitBlockSegments` 按源顺序返回文字段与块，键是文本偏移。追加流式内容只可能延长或切开末尾文字段，前面的块因此保留 React 实例。指令行从正文中移除，两侧拼写与换行逐字节保留。

每个块还会得到由 assistant Turn/step、assistant 文本块序号与源偏移组成的稳定身份。内联选择组使用这个身份，因此两条消息或同一消息里的两个文本块都不会互相替换选择。

## 注册表

`ctx.chatBlocks` 把块 id 映射到 `BlockSpec`。引用规格声明 `size.ratio`、可选 `source` 和接收 `source` 的渲染器。数据规格声明 `content: 'data'`，渲染器接收 `data`、`blockId`、工作区媒体解析器，以及可选的当前会话提交回调。空 id、重复 id、重复来源解析器和非正引用比例都会在注册时失败。

引用来源包括 `raw`、`workspace`、`frame`、`card`，由容器先解析再渲染。已挂载分段订阅注册表版本，晚注册、HMR 注销和来源解析器变化都会刷新现有内容；解析失败显示受控提示，不进入类型渲染器。数据块不会从文件读取组件数据，但媒体字段仍由所在视图解析工作区资源路径。没有 provider 或没有注册任何类型时，仍走原来的 Markdown 路径。

Noven 注册 `code` 和 `module`。`module` 通过现有卡片 API 加载 `card:<cardId>/<moduleId>`，显示共享的只读 `ModuleSurface`。`code` 校验带版本的组件文档，再渲染宿主 React 组件：文字、媒体、图标、纵向分组、分栏、框、标签、图集、配色、角色对话、旁白、单格剧情、设定修订、选项、冲突清单、指标、能力条、柱状图、折线图和雷达图。校验只允许各组件声明的字段，递归拒绝附加字段，并要求可选择组内 id 唯一。它不接受 HTML、CSS、脚本、SVG 源码、任意样式或 base64 媒体，也不创建展示文件或模块。`noven-shell/src/code-catalog.ts` 同时提供模型目录与校验 fixture 的组件 id。

## 框架

引用块在加载前预留声明比例，加载、就绪和失败都不会因此推动转录。数据块使用自然高度，因为完整组件内容已经封闭；媒体和图表各自管理内部几何。无法识别的内联内容显示受控提示，不倾倒原始 JSON。

激活就是焦点。框架可聚焦，`:focus-within` 画出高亮环，Esc 使其失焦。没有组件保存“当前激活块”，也没有文档级监听分配键盘归属。

## 选择与模型可见性

可交互代码组件用稳定组前缀和结构化引用调用当前会话的提交回调。Chat 把组前缀转换成草稿末尾追加或同组单 chip 替换。输入触发器 codec 在发送时把选中引用序列化成普通文字，发送失败沿用现有草稿恢复流程。只读容器不提供回调，选项因此禁用。

块不向模型上报浏览或交互状态。只有用户确认的选择会随下一条消息成为文字。内联组件数据已经属于 assistant 正文，因此这套机制不新增 Session 事件，也不修改 agent-loop。
