# Agent Note: Noven 工作区外壳——同一框架、同一辅助区与归工作区的工作现场

Status: implemented

[English](2026-10-29-noven-workspace-shell.md) | 中文

## Problem

Agent 与 IDE 曾各自形成一套导航、抽屉、折叠和恢复实现。切换模式可能改变控件位置、隐藏工作区选择或丢弃画布。当前工作区没有唯一的选择动作，画布页签又归属于 Session，与“同一工作区内切换会话不得改变项目画布”的产品要求冲突。已验收的交互原型要求一个固定框架只按视图替换内容，而不是两个视图分别补丁。

## Decision

外壳保留同一组稳定宿主，把工作台主体作为唯一产品状态。`FrameLayoutPolicy` 由主体派生（Agent 对话居中、IDE 画布居中），不再来自独立 mode store。`shell.topbar` 放置主体切换；导航开合仍属于导航，固定顶栏下侧栏品牌 mark 是导航顶部唯一的开合控件。框架在侧边列顶部右侧的固定槽位拥有唯一折叠按钮：28px 面板按钮，展开与收起一致；侧边列永远是非主体的一侧，内容头部不再另画折叠。框架同时拥有侧边头部的 trailing 行：壳把侧边主体的上级注册在折叠之前，内容头部只预留这一行的统一宽度，不再各自放置上级。同一个工作区宽度随内容跨模式保留。

`drawer: false` 关闭 `SidebarPanel`、功能导航、自动全屏和呈现轨道上报，但不卸载 `CanvasHost`。此时画布认领独立决定轨道；全局面板独占工作区，非活跃认领保留到返回会话时恢复。固定顶栏在所有平台保留 56px 能力轨，并关闭旧 leading 控件。右侧重复目录和 IDE 临时历史被删除，而不是再用产品 CSS 隐藏。

`WorkspaceNavigator` 把工作区选择器放在可替换内容座之外。Agent 只显示当前工作区的会话，IDE 显示 Noven 目录。`ctx.uiWorkspace.switchWorkspace(id)` 通过现有主选择路径恢复目标工作区最近的普通会话；没有普通目的地时才连接空白会话。该动作保留当前面板，不读写产品模式。折叠导航用同一个工作区选择器和同一组有序会话小窗；目录在展开和折叠呈现中共用父级持有的查询词。导航渲染主体的上级。侧边主体的上级是同一角色在框架 trailing 座里的另一个 provider：侧边是对话时用会话列表，侧边是画布时用目录；从其中选择会展开侧边主体，不改变主体。内容永远不注册自己的上级。

产品外壳只有一个工作台主体（`conversation` 或 `canvas`）；Agent/IDE 是派生标签，框架排布、主体上级和侧边上级都由它派生。新建会话、导入、手作是命令，不是 main 面板：旧的创作主面板目的地已移除，空白会话自己的对话 hero 就是创作起点。社区/消息/我的导航行保留（社区和消息保留「敬请期待」解释，我的仍是真实面板）。框架唯一的侧边折叠是辅助区唯一的可见性状态；旧的 Canvas switch/park 词汇已删除。空白会话 hero 保留薄荷底；根元素上的主体标记把它限定在 Agent 主体，手作里的空白侧边对话不画创作背景。侧边头部只有两组主人：内容自己的 leading（画布页签条、工具、全屏；对话自己的 header 工具）和壳/框架的 trailing（侧边上级再接折叠）。侧边上级与折叠共用折叠基线上的 28×28 一行；侧边对话展开时会话列表与折叠并列，收起时随侧边一起隐藏。画布页签条不创建对象：页签只投影已经打开的对象，`+` 已删除，页签切换只在多于一个页签时出现，对象创建只在目录树里。目录 provider 是会话作用域的子座，由槽渲染器绑定树的 hook 面；Agent 侧画布展开期间壳为当前会话持有一个 Client 引用。

目录行与画布页签共用同一个当前对象键：所有对象行（含用户目录）都从活动画布页签派生 `current`，点击行调用同一个激活动作。实体视图与文件视图共享同一对象全集；视图只切换行名，不改变哪些行存在。文件因此与会话遵守同一条当前项规则。

Noven 对象焦点跟随当前工作区根目录，即使该目录尚未携带创作库项目元数据；旧项目注册表只作回退。对象 Session 的解析也限定在同一根目录。每种模式下的活动对话座都会确保共享画布宿主存在，因此新选 Session 不会丢失工作区画布。非单卡导入先显露 IDE，再展示落点确认。启动时的空白会话路由只在 Agent 执行，进入手作即停止。

画布布局在 `noven.canvas.tabs.v4` 中按工作区归属，对象操作与 I/O 仍保留 Session 身份。旧 v3 数据只读一次且不改写，已有 v4 时绝不回读 v3。页签、活动对象、分屏和工作区绑定跟随工作区，同一工作区内切换会话不替换它们。关闭恢复只不读取已保存值，不删除它。

现有薄荷＋白 token、选中态规则、Create composer、手作路径和导入路径保留。Noven 表面与 BlockNote 变量在 `body` 上随当前 DSH 主题 token 解析，反色按钮与主文字分开，两个编辑器都订阅解析后的主题变化。全局设置模态新增真实的自动保存、画布恢复和行号偏好，统一存入 `noven.shell.workbench.v1`。关闭自动保存后保留草稿供显式保存。终端默认动作打开或激活一个页面，不再生成重复实例；导入则在 IDE 打开第一件真实落点对象。

## Alternatives considered

**分别修 Agent 和 IDE。** 不采用，因为这会保留导致缺陷的分叉实现。现在先共享宿主、状态和控件，再接视图内容。

**把原型 HTML 直接贴进生产。** 不采用，因为原型是行为参照而不是生产架构。现有 Cordis slot、真实 Session 与 Workspace 服务、菜单、编辑器和持久化仍是实现所有者。

**新增一个 currentWorkspace store。** 不采用，因为工作区焦点已经由当前 Session 推导。`switchWorkspace` 走现有选择写入路径，不制造第二个权威。

**继续按 Session 归属画布。** 不采用，因为无法满足同一工作区内切换会话保持项目画布的要求。现在布局归工作区，对象 I/O 归 Session。

**隐藏整个右栏席位，或关闭恢复时删除持久数据。** 不采用，因为抽屉退出不能带走画布，用户也不能丢失页签。现在只退出抽屉，关闭恢复仅拒绝读取旧值。

**重写整个 Web 前端。** 不采用，因为视觉 token、Create、真实编辑器、对话框和数据操作已经可用。本次只替换外壳和归属模型，并复用这些能力。

## Consequences

固定顶栏、当前工作区导航和工作区画布引入了通用 DSH 不必承担的新呈现与导航契约，因此都通过 `FrameLayoutPolicy` 选择性启用；未提供策略或抽屉偏好时保留既有行为。旧折叠别名和 v3 画布读取只是兼容路径，不是第二份状态或降级承诺。

本次不改变 `agent-loop`、`SessionEventMap`、Session 文件、模型可见内容或任一 SDK。开发验收不使用真实用户数据根。未来若再调整工作区身份，仍必须让对象 I/O 绑定正确的 Session，不能仅凭项目元数据再推导一个当前工作区。

## Testing

聚焦套件覆盖布局策略切换、宿主保留、折叠兼容、工作区切换与竞态、折叠导航、抽屉抑制、工作区画布迁移与恢复，以及偏好持久化。Shell 脚本另外覆盖固定顶栏与选中样式。浏览器验收使用隔离 profile、数据根和端口，对照原型验证模式、工作区、会话、对象、导航和辅助区切换，并覆盖响应式、深色呈现及真实创建、编辑、导入、终端和设置操作。浏览器套件还验证品牌 mark 导航开合、侧边折叠在展开/收起前后同一矩形、导航中的主体上级与侧边上级及折叠共用框架 trailing 行、单页签时没有 `+` 也没有切换器、品牌资产，以及文件行（含用户目录和模块视图）与活动画布页签共用同一当前对象。
