# 速览：Noven 桌面端是什么

一个 AI 原生的创作工作台。定位一句话：**AI 是笔，握笔的永远是人**——AI 是全程在场的创作搭档，软件负责把作品、设定、产物组织成用户看得见、摸得着的东西。

## 心智模型（六个概念撑起全部）

| 概念 | 是什么 | 存在哪 |
|---|---|---|
| 项目 | 一个普通文件夹，创作的最小单位 | 任意目录 + `.noven/project.json` 身份标记 |
| 卡 | 结构化的设定文档（世界卡/角色卡），模块化内容 | `卡/<卡名>/` 目录，Finder 可见 |
| 挂载 | 会话和卡的关系：回答身份/背景/管理对象/引用 | 应用侧 `~/.noven/bindings/` |
| 工作台 | 项目里注册为"成果区"的目录，侧栏可浏览 | 目录在项目里，注册表在账本 |
| 创作库 | 登记过的作品清单（草稿/定稿/已发布） | 文件在项目里，登记在账本 |
| 设定管理员 | 每个项目一个常驻会话，自动整理设定进实体库 | 会话 + `.noven/sidecar/entities.json` |

## 文件归属的三层（重要，别搞混）

1. **项目目录 = 用户数据**。`卡/`、作品文件、工作台目录都在 Finder 里看得见摸得着。不删、不藏、不锁进私有格式。
2. **`.noven/`（项目内）= 身份与小状态**。`project.json` 是项目身份标记，`sidecar/` 是实体库。删了能重建，但别替用户删。
3. **`~/.noven/`（应用侧）= 账本**。项目注册表、会话绑定、工作台登记、作品登记——它是**索引**，不是唯一真相。找不到登记不等于文件丢了；反过来登记还在文件没了，会有 missing 标记。

## AI 的能力地图

- **制卡**：`list_cards` / `read_card` / `create_card_bulk` 等一整套管卡工具（详见 `cards`）
- **项目**：`list_projects` + `project` 参数跨项目读写、`move_card` 搬卡（详见 `projects`）
- **工作台/创作库**：`register_workbench`、`register_work` 等（详见 `workbench`）
- **设定管理员**：`list_entities` 等实体工具，另有自动消化循环（详见 `sidecar`）
- **创作辅助**：`generate_image` 生图、`study` 学习资料、内置技能（详见 `creation`）
- **通用能力**：文件读写、命令执行等宿主工具照常可用——但**凡是有专用工具的事，优先用工具**（有校验、有回执、有版本控制），别绕过工具直接改数据文件
