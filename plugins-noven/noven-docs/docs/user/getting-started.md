# 新手使用说明

Noven 是一个 AI 原生的创作工作台：写小说、做 OC、搭世界观，AI 全程在旁边帮忙，但笔在你自己手里。这份说明只讲一件事——**东西都在哪、怎么开始**。

## 两个入口

- **对话**：在创作页输入框里直接说出你的念头（"帮我搭一个有天空群岛的世界"），AI 会和你一起把它做出来。
- **手作**：想自己动手时点「手作」，进入以画布为主的工作台——左边是项目档案，中间是你的案头，右边是助手。

## 项目就是文件夹

每个项目是磁盘上一个普通文件夹，在 Finder 里看得见、摸得着：文稿、卡、图片都在里面。搬走、备份、用别的软件打开，都没问题。

## 卡：世界的零件

- **世界卡**：一张卡装一个世界——规则、地理、势力、历史。
- **角色卡**：一张卡装一个角色——外貌、性格、背景、关系。

卡是模块化的：每个模块可以展开成正文、时间线、集合或地图。同一张卡里的设定会被 AI 当成事实使用。

## 工作台里有什么

从左到右：**档案抽屉**（项目的全部卡和文稿）、**画布**（打开的东西都在这里，以页签切换）、**助手**（随时问 AI，不打断你手头的事）。

画布的起始页是**案头**：预设了你准备好的卡（世界卡、角色卡）和说明书；想从白纸开始，点文稿，一张空白页签就绪。

## 图片

粘贴或拖入图片即可插入正文；拖动图片右下角的手柄可以缩放，宽度会随文稿保存。AI 也能按同样方式设置图片宽度——它和你读的是同一份文稿。

## AI 怎么用

- 对话里让 AI 做事，它建好的卡会以「已建好」的条目交给你，点一下就在画布打开。
- **设定管理员**是每个项目常驻的整理助手：它会把你对话里聊出来的设定归档成实体，草稿要你「收下」才算数。
- 不确定某个功能怎么用，翻说明书，或者直接问 AI——它查的是和你同一份手册。

## 三层文件归属（记住这一条就够）

1. **项目目录** = 你的数据，删了真没了；
2. **项目内 `.noven/`** = 软件的小状态，删了能重建；
3. **应用账本** = 索引，找不到登记不等于文件丢了。

遇到"找不到东西"：先看左边档案抽屉，再看项目文件夹。顺序反过来最容易迷路。
