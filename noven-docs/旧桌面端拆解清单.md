# 诺文旧桌面端拆解清单

> 依据 `../noven-legacy-src` 仓库（v0.1.23）只读源码分析，2026-09-29。相对路径均以 `noven-legacy-src/` 为基准，已逐一验证存在。主工程位于 `creatx/`（Bun workspace 单仓），`docs/`、`prototypes/`、`artifacts/` 为文档与原型。
> 用途：决定移植顺序。**移植=重写**（旧底座 Electron+Cline SDK，新底座 DeepSeek Harness，架构不同；本清单只提供功能/数据/prompt 资产坐标）。

## 一、技术栈概览

- **语言/框架**：TypeScript + Electron 42 + React 19（渲染层），主进程 Node/Electron；Agent 层基于 `@cline/sdk` 0.0.65（ADR-0005 唯一指定 Harness，仅 `creatx/packages/cline-adapter` 允许引用）。
- **构建**：electron-vite 5 + Vite 7 + electron-builder 26（Windows NSIS + Portable x64）；包管理 Bun 1.3（`creatx/bun.lock`、`bunfig.toml`）。
- **运行方式**：`bun run dev` 开发、`bun run package:win` 打包；产物 `诺文-0.1.23-x64-Setup.exe / Portable.exe`（`creatx/electron-builder.yml`）。
- **架构**：主进程 `creatx/apps/desktop/src/main.ts` 装配 14 个 workspace 包（cline-adapter、creative-skills、growth-runtime、world-blueprint、image-runtime、video-runtime、art-library-runtime、workbench、project-files、session-runtime、model-settings、contracts、live-archive-runtime、project-package-runtime）+ 独立静态应用 `creatx/apps/art-library`。
- **测试**：`bun test`（391 个用例级）+ 大量 live/electron 脚本测试（`creatx/scripts/`）。

### 2.4 抖音链接分析（链路完整确认）

- 入口解析：`creatx/packages/video-runtime/src/schema.ts`（`extractDouyinUrl` 支持整段分享文案/v.douyin.com 短链/www.douyin.com/video/<id>/iesdouzin 分享路径）。
- **两条取数路径**（yt-dlp 直连失效后的替代）：
  1. `creatx/apps/desktop/src/douyin-page-extractor.ts`：隐藏 BrowserWindow 加载视频页，用 DevTools 协议截获 `aweme/v1/web/aweme/detail` 自签名响应，取播放地址/标题/作者/时长。
  2. `creatx/apps/desktop/src/douyin-cookies.ts`：独立 `persist:noven-douyin` 分区访问抖音首页换取反爬 Cookie（ttwid/__ac_nonce/msToken/odin_tt），导出 Netscape jar 供 yt-dlp 下载。
- 下载/抽音频/抽帧：`creatx/packages/video-runtime/src/{ytdlp.ts,ffmpeg.ts,frames.ts,subtitles.ts}`；转写 `asr.ts`（外部转写 API）；编排 `service.ts`；清单持久化 `userData/creatx/video/v1`。
- 二进制：`creatx/apps/desktop/vendor/win-x64/`（yt-dlp.exe 2026.07.04 Unlicense、ffmpeg.exe LGPL-2.1，`VENDOR.json` 含 sha256；校验 `creatx/scripts/check-video-vendor.ts`、下载 `fetch-video-binaries.ts`）。
- 移植复杂度：**高**（Electron 专属隐藏窗口+CDP 技巧、Windows exe、外部转写 API 三重依赖；`scripts/douyin-end-to-end.cjs`、`douyin-page-probe.ts`、`douyin-cookie-test.ts` 可作验证工具）。

## 四、数据层

### 4.1 用户项目目录（用户自选文件夹，纯开放格式，无专有容器）

- 内容全部为普通 Markdown/PNG/HTML/JSON（README 示例：`世界观/ 人物/ 地点/ 事件/ 故事/ 地图/ 视觉/`，目录名随作品变化，无强制模板）。
- 项目文件服务：`creatx/packages/project-files/src/index.ts`；忽略 `.git`、`.creatx`、`node_modules`；写入走临时文件+rename（`.creatx-tmp` 后缀）；文本扩展名白名单 `.md/.mdx/.txt/.json/.yaml/.yml/.toml/.csv`，图片 `.png/.jpg/.jpeg/.webp/.gif`。
- **`.creatx/` 内部状态**（对普通文件工具隐藏，禁止 Agent 直写）：`resolve(root, ".creatx", namespace, key)`，已用命名空间：
  - `workbenches/`：工作台注册记录（JSON，v1-v3：id/folder/title/home/visibility）
  - `growth/goals/<goalId>/world/blueprint/{state,index,relations,layers/01..12,reconciliation}.json` 与 `growth/goals/<goalId>/world/materialization/{state,research/,briefs/,extractions/,receipts/,relations}.json`（`creatx/packages/world-blueprint/src/internal-state.ts`）
  - `project-revisions/state.json`（文件版本/修改冲突检测）
- **frontmatter**：项目正文层**不强制** frontmatter；仅两处强约束——传承库安装的 SKILL.md（name/description 须与提交字段逐字一致）；world-blueprint 各文档为 JSON `schemaVersion:3`（层名 12 个中文层、对象 `kind: group|entry`、因果 `type:"causes"` + reason 必填，见 `world-blueprint/src/schema.ts`）。

1. **许可证**：仓库根 `LICENSE` 为 MIT（版权 2025 opencode）。但捆绑二进制另有义务：ffmpeg LGPL-2.1-or-later（`electron-builder.yml` 已带 LICENSE 同发条款）、yt-dlp Unlicense（`vendor/win-x64/VENDOR.json`）；**艺术图集 SPA 来自外部仓 `D:\CodexW\my-art` commit `95b298f`（见 `creatx/apps/art-library/README.md`），其素材/字体许可未在仓库内声明——待确认**；`@cline/sdk` 0.0.65 许可未能验证——待确认；渲染层内置 JetBrains Mono 字体含 `OFL.txt`（`renderer/src/assets/fonts/`）。
2. **Agent Harness 深耦合**：全部创作能力构建于 Cline SDK 之上（`@cline/sdk` shell 工具、Skill 加载、Run/会话模型），仅 `packages/cline-adapter` 可引用（`creatx/scripts/check-cline-imports.ts` 强制）；移植到 DeepSeek Harness 需重写该适配层并保留 Worker 会话隔离（Growth 每阶段隐藏会话）。
3. **Windows 专属代码**：`packages/cline-adapter/src/windows-shell.ts`（PowerShell + UTF-8 前导）；`vendor/win-x64` 仅 .exe（macOS/Linux 需重新走 `fetch-video-binaries.ts`）；NSIS/Portable 打包与 `scripts/install-windows.ps1`；SKILL.md 与契约文档中的 `D:\path\to` 示例路径；`safeArtDirectoryName` 的 Windows 保留名过滤；AGENTS.md/CONTEXT.md 含大量 `D:\CodexW\...` 本机绝对路径（仅文档，不影响运行）。
4. **外部 API 依赖（无本地兜底，失败即关闭）**：文本模型限定 5 种 provider（openai-compatible/openai-native/deepseek/ollama/lmstudio，`creatx/packages/contracts/src/index.ts`）；生图模型枚举 `gpt-image-2-cheap`/`gpt-image-2` 被 SQLite CHECK 硬约束，换模型需迁移队列库；语音转写需单独 Base URL/Key；抖音抓取依赖 Chromium 真实签名（a_bogus 等），反爬策略变更会同时打击两条取数路径。
5. **持久状态分散**：4 个 SQLite 库 + 多个 JSON/目录（见 4.2），其中 Growth 恢复逻辑大量读取 `.creatx/growth/...` 与 `growth.sqlite` 的组合状态；移植时若改变任一路径约定，GWP 的续建/自恢复（`world-entry-recovery.ts`、`growth-runtime/store.ts` 的 predecessor goal 链）会失效。
6. **体积与打包**：ffmpeg.exe 115MB + yt-dlp.exe 18MB 必须留在 asar 外（extraResources）；移植需评估新底座的二进制分发方式。
7. **休眠/未实现项**：`creatx-oc-pro` Skill 未安装（仅测试）；`/living`、世界星图、Cline 子 Agent 并发（CONTEXT.md 记录为失败/延期）不要按已交付能力排期。
