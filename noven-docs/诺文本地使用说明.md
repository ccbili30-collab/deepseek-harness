# 诺文本地使用说明（一页纸）

## 启动

双击仓库根目录的 **`启动诺文.command`**（首次双击若被 Gatekeeper 拦，右键 → 打开一次）。
它会在 3081 端口起服务并自动打开浏览器（每次启动地址带新 token，启动器自动带上，无需手动复制）。

- 手动起：`pnpm dsh web --no-open --port 3081`（需先 `cd 桌面端\ noven`）
- 日志：`/tmp/noven-web.log`
- 已在运行时再双击 = 直接打开页面，不会重启

## 数据都在哪

| 内容 | 位置 |
|---|---|
| 工作台注册表 / 批注 | 各项目内的 `.noven/`（`workbenches.json`、`annotations/`）——**进 git，可随项目走** |
| 技能束落盘 | `~/.noven/skills/noven-{draw-map,draw-comic}/`（插件激活时自动刷新） |
| 生图落盘 | 会话项目内，默认 `视觉/` 目录（设置页可改） |
| 插件源码 | 仓库 `plugins-noven/`（六个：study / brand / image / workbench / draw-map / draw-comic） |

## 生图 Key（首次必做）

设置（左栏 ⚙）→ **生图** → API Key（存系统凭据域，不落文件）+ 接口地址 + 模型名。
也可用环境变量：启动前 `export NOVEN_IMAGE_API_KEY=...`。

## 三条命令

- `/study [范围]` — 学习项目资料，提炼设定/文风/画风
- `/draw-map [需求]` — 世界观 → 可点击交互地图（底图→掩码→构建→注册工作台，全自动）
- `/draw-comic [章节]` — 故事 → 分镜连续、字模分离的漫画页

## 更新代码后的流程

```
git pull && pnpm install && pnpm run build   # 核心有变才需要
cd plugins-noven && pnpm -r build             # 插件有变才需要
# 重启：杀掉现有进程（pgrep -f "dsh web" ）后再双击启动诺文.command
```

## 常见问题

- **打不开页面**：看 `/tmp/noven-web.log`；端口被占就改启动器里的 `PORT`
- **插件没生效**：`~/.dsh/profiles/web/package.json` 的 bundles 列表里应有六个 noven-*；缺哪个就 `pnpm dsh plugin --profile web add link:<绝对路径>`
