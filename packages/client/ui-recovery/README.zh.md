# @deepseek-ai/dsh-client-ui-recovery

[English](README.md) | 中文

恢复中心是展开侧边栏底部“设置”右侧始终可见、形似电源键的入口；侧栏收窄时，它位于“设置”上方。紧凑菜单有意只保留创建检查点、回档至最近检查点和安全关机。设置页的“恢复与回档”栏目负责检查点历史、存储／源码路径、载荷校验、检查点选择与精确 ID 回档确认。

快捷回档会显示最近发布的检查点，并要求再次明确确认；选择任意检查点则必须在设置页输入完整 ID。浏览器本身从不编辑文件：它调用仅限本机回环访问的 `recovery` Remote；Host 关闭前，Remote 会把执行权交给进程外 guardian。安全关机使用 launcher 提供的有边界 `appExit` 路径，不启动替代进程。即使尚无任何检查点，电源菜单也始终可见，让用户能直接发现并执行第一步安全操作。

## 模型体验

无，因为本浏览器 UI 不注册提示词、工具、消息或提供方请求。

#### KV Cache 影响

无；本包从不组装模型输入。

## 已知限制与暂缓事项

- 面板目前给新检查点使用固定的手动标签；自定义标签仍可通过 CLI 设置。
- 恢复 profile manifest 后的依赖协调仍会明确报告为手动后续操作。
